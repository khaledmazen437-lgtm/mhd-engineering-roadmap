# MHD Tech — Engineering Projects Roadmap

> صفحة تعرض خارطة مشاريع هندسية (إنترنت الأشياء والأنظمة المدمجة) بتصميم تفاعلي.

A single-page showcase of engineering/IoT project ideas — smart lighting, library occupancy, RFID attendance, a Wi-Fi IDS monitor, a web-guided robot and more — with a glitch-style hero and interactive cards.

## Features

- Project cards covering embedded systems and IoT builds
- Glitch-effect hero typography, fully RTL Arabic content
- Pure front-end: no backend, no build step

## Tech Stack

- Vanilla HTML/CSS (`index.html` + `style.css`)

## Running

Open `index.html` in a browser.
