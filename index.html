نظام الإنارة الذكي

اضغط للتفاصيل

نظام الإنارة الذكي للممرات

نظام أتمتة (Home Automation). يعتمد على اكتشاف حرارة الجسم البشري عبر حساس PIR، ليقوم بإعطاء أمر لريلاي بفتح دائرة كهربائية (220V). بمجرد خروج الشخص، يبدأ النظام في عد (30 ثانية) باستخدام مؤقت برمجي، ثم يفصل الكهرباء تلقائياً.

🛒 المشتريات (BOM):

  • ESP32 Development Board.
  • حساس حركة HC-SR501 PIR Sensor.
  • موديول Relay 1-Channel 5V.
  • لمبة 220V، دواية، فيشة، وأسلاك مجدولة.

👥 المهام والخبرات:

  • مهندس الهاردوير: توصيل خط الـ 220V بالريلاي وعزله بشريط لحام لمنع الماس الكهربائي.
  • مطور C++: قراءة إشارة الحساس، وبرمجة خوارزمية Timer (باستخدام millis).

مؤشر إشغال المكتبة

اضغط للتفاصيل

مؤشر إشغال المكتبة الذكي

نظام إحصائي حي. حساسين على الباب بمسافة 10 سم. قطع الحساس (أ) ثم (ب) = دخول، والعكس = خروج. إرسال العدد الصافي لـ Firebase وتحديد الحالة (مزدحمة، متوسطة، فارغة) على لوحة تحكم ويب.

🛒 المشتريات (BOM):

  • ESP32 Development Board.
  • 2 حساس IR Obstacle Avoidance Sensor.
  • شاحن 5V للتشغيل الدائم.

👥 المهام والخبرات:

  • مطور C++: خوارزمية تمنع العد المزدوج (Debouncing)، وتحديد الاتجاه، ورفع المتغيرات.
  • مطور Front-End: Dashboard بـ React و Tailwind تسحب الرقم وتغير لون الواجهة ديناميكياً.
مستوى 3

لوحة الإعلانات الرقمية

اضغط للتفاصيل

لوحة الإعلانات الرقمية الديناميكية

شاشة تُعلق في أروقة الكلية. تستدعي التنبيهات من API مخصص وتعرضها بشكل متحرك (Scrolling). الإدارة بالكامل من Admin Panel مبرمجة خصيصاً.

🛒 المشتريات (BOM):

  • ESP32 Development Board.
  • شاشة ليدات MAX7219 Dot Matrix 4-in-1.
  • محول طاقة خارجي 5V/3A Adapter.

👥 المهام والخبرات:

  • مطور Full-Stack: بناء Admin Dashboard بـ React لكتابة الإعلان وحفظه في Node.js/Firebase.
  • مطور C++: استخدام مكتبة MD_Parola للـ Scrolling Text، ومكتبة ArduinoJson لاستقبال الـ API.
مستوى 4

شاشة قاعات المحاضرات

اضغط للتفاصيل

شاشة قاعات المحاضرات الذكية

شاشة ملونة على باب المدرج تتزامن مع الوقت (NTP). تسحب الجدول من API وتعرض: (المحاضرة الحالية، القادمة، والدكتور).

🛒 المشتريات (BOM):

  • ESP32 Development Board.
  • شاشة ملونة TFT LCD 2.8" SPI (ILI9341).
  • علبة أكريليك للتغليف (Enclosure).

👥 المهام والخبرات:

  • مطور Web: بناء CMS مصغر لإدخال أيام وأوقات المحاضرات وتصديرها كـ JSON.
  • مطور C++: استخدام TFT_eSPI لرسم الواجهة، ومقارنة الوقت الحالي بالجدول.
  • مهندس الهاردوير: توصيل دقيق لأطراف الـ SPI (MOSI, MISO, SCK).
مستوى 5

نظام الحضور بالـ RFID

اضغط للتفاصيل

نظام الحضور والانصراف (Full-Stack)

الطالب يمرر الكارت، الـ ESP32 يرسل الكود المشفر لـ Node.js API. السيرفر يسجل الحضور ويرد لتشغيل LED أخضر/أحمر وصوت إنذار.

🛒 المشتريات (BOM):

  • ESP32 Development Board.
  • قارئ كروت RFID-RC522 + ميداليات ذكية.
  • Active Buzzer + 2 LED + مقاومات.

👥 المهام والخبرات:

  • مهندس Back-End: REST API يستقبل الطلبات ويسجلها في MySQL/MongoDB.
  • مطور Front-End: واجهة Admin لحظية لعرض الحضور.
  • مطور C++: برمجة بروتوكول SPI، وإدارة رد السيرفر لتفعيل الإنذار.
مستوى 6

مراقب شبكات Wi-Fi (IDS)

اضغط للتفاصيل

مراقب الشبكات الأمني (Cybersecurity)

أداة Blue Team. يدخل الـ ESP32 في Promiscuous Mode لالتقاط حزم البيانات (Packets) في الهواء، واكتشاف هجمات الـ Deauth أو الشبكات المزيفة وعرض الـ MAC للمهاجم.

🛒 المشتريات (BOM):

  • ESP32 Development Board.
  • شاشة دقيقة OLED 0.96" I2C.
  • Active Buzzer + Power Bank للتشغيل الميداني.

👥 المهام والخبرات:

  • خبير شبكات: فهم بروتوكول 802.11 وتمييز الـ Management frames.
  • مطور C++ متقدم: تفعيل Monitor Mode وتحليل الـ Packets لحظياً، وبرمجة الشاشة.
مستوى 7

الروبوت الموجه بالويب

اضغط للتفاصيل

الروبوت الجامعي الموجه بالويب

روبوت بعجلتين يتحرك بأوامر من Web App. مزود بذكاء ذاتي لتجنب الاصطدام. الـ ESP32 يعمل كـ Web Server يستقبل الأوامر من الهاتف عبر الواي فاي.

🛒 المشتريات (BOM):

  • شاسيه روبوت 2WD Smart Car Kit + L298N Motor Driver.
  • ESP32 Development Board.
  • 3 حساسات Ultrasonic (HC-SR04).
  • 2 بطارية 18650، حامل، وموديول LM2596 لخفض الجهد.

👥 المهام والخبرات:

  • مطور Front-End: تصميم Web App كعصا تحكم (Joystick) يتصل عبر WebSocket.
  • مهندس الهاردوير: تجميع ميكانيكي، وضبط مسارات الطاقة القوية لمنع ريستارت الـ ESP32.
  • مطور C++: خوارزميات PWM للسرعة، ودمج قراءات 3 حساسات لتفادي العقبات.
